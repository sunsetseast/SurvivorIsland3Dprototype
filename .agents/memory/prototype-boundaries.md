---
name: Prototype boundaries
description: Standing product scope and geographic-reference constraints for the Survivor camp prototype.
---

Keep the camp prototype isolated from Replit project “Survivor Island 25” and
GitHub repository sunsetseast/SurvivorIsland2025. Do not mutate, merge, deploy,
or claim integration with the original game; do not publish publicly.

**Why:** The user explicitly required a separate playable prototype, not changes
to their existing game.

**How to apply:** Original project resources are read-only geographic references.
Any future integration or publication needs a new explicit instruction.

The user works using only iPhone, ChatGPT, GitHub and Replit, with no MacBook.

**Why:** The user stated this constraint and requested landscape iPhone Safari.

**How to apply:** Provide phone-usable previews and controls; do not prescribe
Mac-only tools or desktop-only steps.

Geography is provisional, even when based on the experimental map branch.

**Why:** The reference map has no metric scale or compass, and the reference
branch explicitly labels its coordinate proposals unapproved.

**How to apply:** Distinguish observed landmark relationships from invented
distances, elevations and routes; do not present the prototype as an approved map.
