# Real WebGL evidence

Generated by `pnpm --filter @workspace/survivor-camp-prototype qa:tribal`.

`01`–`11`: arrival, reveal, wide Council, staggered stumps, central fire, jury, voting exterior/interior, host/exit, stars/architecture and 844×390 landscape gameplay. `viewport-*` adds the other requested sizes. `intro-*` shows the drone, masonry detail, standing Jeff, survivor arrival, seating and player handoff. All are real Chromium WebGL captures from this implementation. Caption timers are allowed to commit after accelerated game frames before capture.

The JSON report records routes, grounding, camera probes, renderer identity, frame timings and errors. Software-rendered screenshots and automated touch events do not substitute for a physical iPhone Safari test.
