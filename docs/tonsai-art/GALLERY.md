# Production WebGL gallery

56 genuine before/after images: 12 native Player views and two explicitly labeled inspection views, in both quality profiles. Native camera coordinates match exactly. Production Chromium 153 / ANGLE SwiftShader, 932 × 430, DPR 1, touch viewport. These images are actual game renders. Cloud animation phase can differ across page loads; the sky implementation was not changed by this PR.
