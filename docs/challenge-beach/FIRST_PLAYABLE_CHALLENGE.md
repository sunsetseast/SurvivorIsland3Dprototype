# Recommended first fully playable challenge

Implement a short **Stillwater Balance** individual trial in the existing individual clearing. It uses an already modeled station and needs no new swimming, climbing or team-coordination locomotion.

## Bounded playable slice

1. Enter through the existing explicit rehearsal grant until a real event authority exists. Select the current station configuration and validate player/contestant poses.
2. Add an opt-in station interaction using the existing control-lock/input-reset ownership. Present one compact touch/keyboard balance-and-placement control, with accessible sensitivity and clear feedback.
3. Run a 60–90 second original balance/stacking task. Use deterministic lightweight state and authored motion, without a rigid-body physics engine. Distinguish player success/failure from the visual prop pose.
4. Provide restart, cancel and return-to-exploration behavior. Scope temporary score/results to the rehearsal; do not award season immunity/rewards or invent production admission.
5. Add a small deterministic opponent rehearsal only after the player's loop is verified. Continue reading contestant identities from the existing owner; do not create a second social/provider runtime.

## Acceptance

A player can enter, understand the controls, complete or fail one trial, retry, cancel midway, and return to the exact originating camp without stuck inputs or leaked station state. Keyboard and multitouch tests cover focus/blur, cancellation, repeated attempts and scene departure. Verify on a physical iPhone before committing to touch difficulty, performance targets or production event rewards.
