# Verification boundaries and remaining model limits

- No physical iPhone 17 Pro Max is attached. Trusted touch sequences run in Chromium software WebGL with mobile landscape emulation; existing mobile regression also runs desktop WebKit. These do not certify physical Safari performance or subjective control feel.
- Characters remain the existing stylized procedural meshes. Hands are part of forearms and toes are part of feet; no finger grip or toe articulation. Shared states can later feed higher-quality animation clips.
- Traversal uses authored two-link limb targets and joint poses, not full-body IK or rigid-body physics. Crawl clearance and net contact are measured against actual rendered transforms; contact tolerances acknowledge the existing stylized mesh surface and rope spacing.
- The deterministic beam penalty remains two seconds. Presentation shows a drop, return stride and recovery without changing the race clock or simulation checkpoint rules.
- Camera collision uses marked solid meshes, cached instance bounds, authored equipment capsules, conservative per-mass challenge cliff bounds and terrain sampling. Foliage alpha cards are intentionally excluded. Thick visible trunks and solid equipment receive collision envelopes.
- The movement basis stays fixed for a continuous joystick gesture to avoid orbit feeding back into travel. Release/reapply to move relative to the newly inspected camera direction.
- This PR preserves the existing course and environments. It does not improve course decoration, replace characters, redesign UI or ship a public build.
