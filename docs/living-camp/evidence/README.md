# Actual WebGL evidence

Generated by `artifacts/survivor-camp-prototype/scripts/living-camp-qa.mjs` from the
running Vite application in Chromium 130 headless-shell with SwiftShader.
These are genuine renders, not mockups or generated images.

The harness drives real player input and NPC path following. For reproducible
route/interaction checks it holds autonomous decision deadlines and issues a few
explicit destination intents. It never changes character coordinates to reach a
screenshot. It later restores the opportunity provider for 120 simulated seconds.
Intermediate game frames use the actual Fiber movement, camera and rig callbacks
with GPU draws suppressed; each capture renders the real scene. Portraits alone
use manually framed diagnostic cameras. These staging details matter: screenshots
show implemented behavior, not proof of full season simulation.
