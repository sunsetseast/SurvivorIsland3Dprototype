# Cast art specifications

The original [2D avatars](https://github.com/sunsetseast/SurvivorIsland2025/tree/cf894e578d77fce1e588d793dfc8d14f61ec7628/Assets/Avatars) set the palette and identity cues. The season references guide anatomy, clothing and silhouette. The wardrobe can combine details from different appearances. The 2D repository is a read-only reference and no reference image is bundled with this work.

The palette uses warm, matte skin with restrained variation, directional highlights in hair, and sun-faded expedition fabrics. Define the jaw, cheek planes, brow and nose before adding surface details. Check each character with their hair and wardrobe hidden as well as with the full outfit so accessories cannot compensate for a generic face.
